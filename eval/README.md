# eval/

Jeux d'évaluation construits à la main (versionnés) :

- `retrieval_queries.jsonl` : questions d'avocat + clauses pertinentes jugées à la main (volet C, C3) ;
- `counterfactuals/` : paires (clause originale, clause perturbée) pour l'audit (volet C, C7) ;
- `ood/` : clauses hors distribution (style européen, français) pour l'audit.
